# 前后端改造与验收记录

记录日期：2026-10-01。对应当前源码，不是未来规划的完成清单。

## 1. 本轮实际改造

| 范围 | 原问题 | 当前实现 |
|---|---|---|
| 居民列表 | 依赖浏览器本地记录 | 登录用户按服务端 owner 查询，可跨设备读取 |
| 记录筛选 | 只过滤当前页 | MySQL 动态条件查询全部可见范围 |
| 详情授权 | 登录即可按编号读取 | 居民核对 requesterId，管理员可读全部 |
| 分页协议 | 直接暴露 PageImpl | 自定义 PageView，固定字段 |
| 排序 | 缺少稳定第二排序字段 | createdAt DESC, id DESC |
| 分页输入 | 依赖框架默认处理 | 限制页码、页大小、关键词长度 |
| 幂等 | 仅 Redis 临时标记 | 用户与幂等键 DB 唯一、正文一致性检查、结果回放 |
| 租约释放 | 直接 DEL | 随机 owner + Lua compare-and-delete |
| 分配 | 请求状态判断前未锁求助行 | 先锁请求、再锁库存，拒绝重复分配 |
| FEFO | NULL 有效期可能先分配 | 无有效期批次明确排最后 |
| 创建时间 | 保存后内存字段可能为空 | Hibernate 读取数据库生成的 createdAt |
| 消息发布 | convertAndSend 返回即标记成功 | 等待 confirm、检查 mandatory return |
| 限流 | INCR 与 EXPIRE 分离 | Lua 原子计数及首次设过期 |
| HTTP 错误 | 部分错误掉入 500 | 参数 400、认证 401、权限 403、并发冲突 409 |
| Trace ID | 接受任意外部字符串 | 字符和长度限制 |
| JWT | header 未明确固定 | 验证固定 HS256 header |
| 前端重试 | 每次点击产生新幂等键 | 相同内容失败重试保留键，成功后清理 |
| 前端搜索 | 无服务端全局搜索 | 防抖请求、版本号防止旧响应覆盖 |
| 前端错误 | 可能混成空列表 | 失败面板与重试入口 |

## 6. 幂等与可靠性保证表

| 条件 | 当前行为 | 注意事项 |
|---|---|---|
| 同用户同键同正文，已有 DB 记录 | 返回原请求当前状态 | Redis 标记是否过期不影响回放 |
| 同用户同键换正文 | 409 | 新业务需要新键 |
| 新请求 Redis 不可用 | 请求失败 | 尚未实现纯 DB 降级创建 |
| DB 提交后 Redis 完成标记失败 | 本次可能返回失败；同键重试可回放 | 超时并不意味着没有创建 |
| 相同请求同时分配 | 请求行锁串行检查 | 只允许 PENDING 进入 |
| 无库存 | 409，分配事务不提交 | 并非技术错误 |
| MQ 确认超时或不可路由 | Outbox 记录失败并重试 | 等待发生在批量事务中，存在吞吐限制 |
| 发送确认后 DB 标记前崩溃 | 可能再次发送 | 消费者必须处理重复 |
| 真实外部通知副作用 | 尚未实现 | 模拟 Redis 去重日志不能视为 exactly-once |
